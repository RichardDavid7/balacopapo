# Módulo `:feature:settings`

- **Camada:** Feature UI (Jetpack Compose)
- **Responsabilidade:** Painel de configurações do aplicativo: perfil/instância conectada, preferências globais de Áudio/Opus (Voz vs Música, Estéreo, Bitrate Auto/Manual, Suspensão em inatividade), Volume do Soundboard, Vídeo (*ocultar participantes sem vídeo*), checagem de atualizações (GitHub Releases / Obtainium) e logout.
