# Módulo `:feature:soundboard`

- **Camada:** Feature UI (Jetpack Compose)
- **Responsabilidade:** Tela do Soundboard listando sons do Espaço e da Instância (`GET /api/soundboard?spaceId=`), busca rápida, controle de volume (slider roxo Aether Drift) e disparo com 1 toque via `BackspaceVoiceEngine.playSoundboardSound`.
